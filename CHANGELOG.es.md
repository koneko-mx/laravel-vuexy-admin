### \[1.0.0-beta] - 2025-05-29

**Agregado**

* Primera versión pública del componente Laravel Vuexy Admin (versión beta)
* Arquitectura modular tipo ERP lista para sistemas multi-tenant
* Integración con Laravel 11, Fortify, Livewire 3, y Spatie Roles y Permisos
* Soporte para PostgreSQL y Redis
* Registro de auditoría con OwenIt Laravel Auditing
* Diseño de layout administrativo dinámico y modular (requiere plantilla Vuexy con licencia legal)
* Comandos para publicación de configuraciones y recursos
* Seeders con roles y permisos predeterminados
* Interfaz en español orientada al mercado mexicano
* Sincronización entre GitHub y repositorio Git privado

**Notas**

* Esta versión es funcional, pero aún está en fase beta.
* La plantilla Vuexy Admin es obligatoria para compatibilidad completa de UI (no incluida).
* Licenciado bajo Business Source License 1.1 con transición futura a MIT.
